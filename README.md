# 📱 Student Sleep & Smartphone Analytics

### Investigating the Association Between Smartphone Usage Patterns, Sleep Quality and Daytime Functioning Among School Students in Sri Lanka Using Machine Learning

---

## 📌 Project Overview

Student Sleep & Smartphone Analytics is a research-oriented data science project that aims to investigate the relationship between smartphone usage patterns, sleep quality, and daytime functioning among school students in Sri Lanka.

The project explores how digital device usage habits may influence students' sleeping patterns, concentration, alertness, and daily academic functioning.

Using data analytics, statistical techniques, and machine learning approaches, this research aims to identify meaningful patterns and develop predictive models that may help understand the relationship between smartphone usage and student sleep health.

## 🎯 Research Objectives

- Analyze smartphone usage patterns among school students in Sri Lanka.
- Investigate the association between smartphone usage and sleep quality.
- Examine the relationship between sleep quality and daytime functioning.
- Identify important factors associated with poor sleep quality.
- Apply machine learning techniques to explore predictive patterns.
- Generate data-driven insights to support student sleep health awareness.
